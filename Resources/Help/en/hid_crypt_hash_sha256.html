SHA-256 (Menu Individual Procedures \ Hash)

Like SHA-224, SHA-384 and SHA-512, the SHA-256 algorithm (Secure Hash Algorithm) is part of the so called SHA-2 family of hash functions. SHA-256 yields a hash value of 256 bit (32 byte) and is the successor of the SHA-1 algorithm.

As of today, the NIST recommends the SHA-2 family: "Federal agencies should stop using SHA-1 for digital signatures, digital time stamping and other applications that require collision resistance as soon as practical, and must use the SHA-2 family of hash functions for these applications after 2010." Critical applications for quite some time employ SHA-2 algorithms (i.e. VeraCrypt (former TrueCrypt) uses RIPEMD-160, SHA-512 and Whirlpool).

This algorithm family is described as Secure Hash Standard (SHS) in FIPS 180-2 and FIPS 180-3.

Similar to the AES competition, a successor to SHA-2 is sought after with the help of NIST workshops.
