MARS (Menu Encrypt/Decrypt \ Symmetric (modern) \ Further Algorithms)

The MARS encryption algorithm works with a block length of 128 bits and a variable key length, which can be 128, 192 or 256 bits.

CrypTool uses MARS in CBC mode with zero initialization vector and 01-00 padding.

The key is entered in the Key entry dialog.

CrypTool contains a tool which performs a brute-force attack on the MARS encryption algorithm.
